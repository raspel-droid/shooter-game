A simple space shooter game built with Python and Pygame.
Move your rocket left and right to avoid enemy UFOs and shoot them down before they reach the bottom of the screen.

Features

Player-controlled spaceship

Enemy UFOs that move downward

Shooting bullets with Spacebar

Sound effects for firing and background music

Win by reaching the score goal

Lose if too many enemies slip through or collide with you

---------------------------------------------------------

Assets Needed

Make sure the following files are in the same folder as the game:

galaxy.jpg → background image

rocket.png → player sprite

ufo.png → enemy sprite

bullet.png → bullet sprite

space.ogg → background music

fire.ogg → firing sound

Controls

← / → → Move left or right

Spacebar → Fire bullets

---------------------------------------------------------

Game Rules

Hit 10 UFOs to win.

If 3 UFOs escape or you collide with one, you lose.
